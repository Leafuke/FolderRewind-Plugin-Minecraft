# Versioned map colors

Unmodified generated color mappings from Querz/MCA Selector, commit d31bee6a7a4e894f250bb3ab47347e8c85b6ca5a.
Source: https://github.com/Querz/mcaselector/tree/d31bee6a7a4e894f250bb3ab47347e8c85b6ca5a/src/main/resources/mapping
Copyright 2018–2026 Querz. MIT license: MCASelector.LICENSE.txt (also embedded and included in the plugin package).

Runtime mapping thresholds follow the corresponding upstream ColorMapping classes: 2834, 3080, 3207, 3940, 4536, 4764. SurfaceReader independently restricts supported release DataVersions. To update, pin a reviewed upstream commit, copy only the needed JSON files, update thresholds and preserve this attribution. No Minecraft JARs or original textures are distributed. C# lookup/tint and terrain/water shading are adapted from the MIT-licensed mapping/color and tile/TileImage implementations.
